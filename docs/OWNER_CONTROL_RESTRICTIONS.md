# Restrictions and behaviour-affecting mechanisms

Generated by `tools/restriction_register.py` from `docs/backlog/restrictions.json`. Do not edit this file by hand.

Every mechanism in this repository that restricts, shapes or gates what Cognitive Nexus says or does, as found on 2026-11-23 and as it is now. It was made for the owner's Priority 0 requirement (docs/owner/): the owner asked for an assistant with broad conversational freedom and exactly one content rule, and for conversation behaviour, model and provider limits, tool permissions and security protections to be kept apart. The plain-language account, the decisions and the measurements are in docs/OWNER_CONTROL.md.

## How to read this

- **Category** says which layer a mechanism belongs to. The layers are kept apart in the code as well: conversation rules are not tool permissions, and neither is a security protection.
- **Status**: *active* (in the code now), *changed* (still there, altered by the owner-control work), *removed* (gone; the check confirms the quoted code is no longer in the file).
- **Where** quotes a line of the code and gives its current line number, looked up when this file was generated.
- **Owner requested** and **Origin** say who asked for a mechanism. "Earlier AI-written code" means it was in the repository before this work and no owner request for it is recorded.
